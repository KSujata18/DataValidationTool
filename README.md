# Data Validation Tool

## Overview
A C# console application that reads employee data from a CSV file, validates records, generates a clean output file, and creates detailed error reports.

## Features
- Read CSV files
- Parse employee records
- Validate required fields
- Validate numeric fields
- Validate age range
- Generate output.csv
- Generate errors.txt

## Technologies
- C#
- .NET
- Visual Studio
- Git
- GitHub

## Sample Input

ID,Name,Age,Salary
1,John,25,50000
2,Mary,30,60000

## Output

Valid records are written to output.csv.

Invalid records are written to errors.txt.
